# Game Death Counter

[Citadel](../../README.md) › Game Death Counter

Compteur de morts pour les jeux de type Souls, sur la route `/game-death-counter`. Chaque jeu a ses boss, chaque boss ses morts, datées et commentées ; un bouton « +1 » ajoute une mort à l'instant. Boss vaincus et jeux terminés se marquent, et chaque total se calcule seul.

## Lancer

Inclus dans Citadel, sans prérequis propre : voir [Lancer en local](../../README.md#lancer-en-local), puis http://localhost:3001/game-death-counter.
