# Pour lancer ce projet :

## Prérequis
- Remplir le .env à partir du .env.example
- Installer MariaDB
- Installer Docker ou Docker Desktop
- Installer Node

## Démarrage
- Exécuter le script `init-db`
- Exécuter le script `migrate`
- Installer les dépendances
- Lancer avec `start`
